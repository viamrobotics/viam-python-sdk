class viam.services.navigation.Status(*, position: Global___Position | None = ..., localized: bool = ..., velocity: Global___Velocity | None = ..., goal: Global___GoalStatus | None = ..., updated_at: google.protobuf.timestamp_pb2.Timestamp | None = ..., extra: google.protobuf.struct_pb2.Struct | None = ...)

Bases: google.protobuf.message.Message

Status is the robot navigation state returned by GetNavigationStatus and by methods that start, suspend, or resume motion. The robot is idle when goal is unset or goal.state is terminal. It is moving when goal.state == GOAL_STATE_ACTIVE. Methods that start motion fail while localized is false.

localized: bool

Pose is trusted; false blocks new goals

position() → Global___Position

Same as GetPosition

velocity() → Global___Velocity

Current body-frame velocity; zero when stopped

goal() → Global___GoalStatus

Latest goal; unset until the first one

updated_at() → google.protobuf.timestamp_pb2.Timestamp
extra() → google.protobuf.struct_pb2.Struct

async close()

Safely shut down the resource and prevent further use.

Close must be idempotent. Later configuration may allow a resource to be “open” again. If a resource does not want or need a close function, it is assumed that the resource does not need to return errors when future non-Close methods are called.
