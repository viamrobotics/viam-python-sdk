class viam.proto.common.GeoPose(*, location: Global___GeoPoint | None = ..., altitude: float | None = ..., heading: float = ..., orientation_vector: Global___Orientation | None = ...)

Bases: google.protobuf.message.Message

GeoPose is a GPS position and orientation, optionally with altitude.

Orientation is expressed in the east-north-up tangent frame at location: +X east, +Y north, +Z up. Viam base axes are +X right, +Y forward, and +Z up, so the identity orientation (o_x, o_y, o_z, theta) = (0, 0, 1, 0) is level and faces north: forward is north and right is east.

The same rotation as an orientation vector is Viam’s Tait-Bryan Euler sequence, intrinsic z-y’-x’’ (yaw, then pitch, then roll), in degrees:

  • yaw: right-handed rotation about local up (+Z). Zero faces north. Positive yaw is counterclockwise viewed from above, so a compass heading in degrees clockwise from north is the negation of yaw.

  • pitch: right-handed rotation about the base’s forward axis (+Y).

  • roll: right-handed rotation about the base’s right axis (+X). With pitch 0, positive roll raises the forward axis; that angle is the elevation of forward above the local horizon.

Exactly one of heading or orientation_vector is set. heading is only the compass yaw of a level pose (pitch 0, roll 0). It is not added to orientation_vector.

altitude: float

Optional altitude in meters

heading: float

pitch 0, roll 0.

Type:

Compass heading in degrees, clockwise from north. Level pose

location() → Global___GeoPoint

Latitude and longitude in degrees

orientation_vector() → Global___Orientation

Full orientation in the east-north-up tangent frame at location. o_x, o_y, o_z, theta in degrees, same orientation vector as Pose.

class viam.proto.common.Pose(*, x: float = ..., y: float = ..., z: float = ..., o_x: float = ..., o_y: float = ..., o_z: float = ..., theta: float = ...)

Bases: google.protobuf.message.Message

Pose is a combination of location and orientation. Location is expressed as distance which is represented by x , y, z coordinates. Orientation is expressed as an orientation vector which is represented by o_x, o_y, o_z and theta. The o_x, o_y, o_z coordinates represent the point on the cartesian unit sphere that the end of the arm is pointing to (with the origin as reference). That unit vector forms an axis around which theta rotates. This means that incrementing / decrementing theta will perform an inline rotation of the end effector. Theta is defined as rotation between two planes: the first being defined by the origin, the point (0,0,1), and the rx, ry, rz point, and the second being defined by the origin, the rx, ry, rz point and the local Z axis. Therefore, if theta is kept at zero as the north/south pole is circled, the Roll will correct itself to remain in-line.
